# 3言語オフライン翻訳（iPhone向けPWA）

日本語・モンゴル語・英語の相互翻訳を行う、端末内推論を目指したPWAの試作です。

## 重要な注意
- iPhoneのSafariで使うには、HTTPSで公開する必要があります（GitHub Pagesなど）。
- 初回のアプリ読み込みと翻訳モデルのダウンロードにはインターネット接続が必要です。
- モデルの準備完了後は、モデルファイルをブラウザキャッシュから読み込み、端末内のWASMで翻訳します。SafariのWebサイトデータ削除、容量不足によるキャッシュ削除、OSによるデータ消去後は再ダウンロードが必要です。
- iPhoneのメモリやストレージにより、モデルの読み込みに失敗したり、動作が遅くなったりする可能性があります。実機での検証が必要です。初回はWi-Fi接続・十分な空き容量を推奨します。
- この試作は音声入力・音声読み上げ・翻訳履歴には未対応です。
- 入力文は翻訳APIに送信しない設計ですが、初回のライブラリ／モデル取得では外部配信元へ接続します。

## iPhoneへの導入
1. このフォルダの中身をGitHubの新しいリポジトリにアップロードします。
2. GitHubリポジトリの Settings → Pages で、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 発行された `https://...github.io/.../` のURLをiPhoneのSafariで開きます。
4. 「共有」→「ホーム画面に追加」を選びます。
5. アプリを開き、「翻訳モデルを準備する」を押します。Wi-Fiで完了するまで待ちます。
6. 準備完了後、機内モードにして翻訳できるか実機テストしてください。

## 翻訳モデル
`Xenova/nllb-200-distilled-600M` を Transformers.js から読み込みます。NLLBの言語コードは日本語 `jpn_Jpan`、モンゴル語（ハルハ）`khk_Cyrl`、英語 `eng_Latn` です。
